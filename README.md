# Go2 Soccer

A personal robot-learning research portfolio by **Lishengqi Jiang**.

The project covers task-specific reward and curriculum design, policy training,
physical-behavior evaluation, and the composition of learned soccer skills in
NVIDIA Isaac Lab. Research guidance is provided by Eugene Vinitsky and Benjamin
Rivière at New York University.

The website focuses on measured scoring progress, task-level training decisions,
and demonstrated skills in simulation. Five selected shooting checkpoints use
the same 1,472-case development benchmark. Task-specific work builds on existing
simulation and reinforcement-learning software.

## View locally

Open `index.html` in a browser. Keep the `assets` directory beside it. Chart data
is included locally; no build process, account, or server application is needed.

## Hosting

This repository contains only the public website and its presentation assets.
For GitHub Pages, publish the `main` branch from the repository root. The
`.nojekyll` file enables static-file publishing.

The `downloads` folder contains an offline copy of the website. Model weights,
private training logs, experiment source, and development-tool configuration are
not included.
